# 💫 Sobre mí:

<p align="center">

Soy **Tecnólogo en Análisis y Desarrollo de Software**, apasionado por la arquitectura **backend**, la construcción de APIs robustas y el desarrollo de soluciones web escalables y modulares. 

Cuento con experiencia sólida en el diseño y despliegue de plataformas completas combinando entornos **Node.js (Express, Prisma ORM)** y **PHP (Laravel)**, complementados con **Vue.js**, **Docker** y bases de datos como **PostgreSQL** y **MySQL**. También desarrollo integraciones personalizadas y herramientas de automatización comercial (como chatbots y CRM con la API de WhatsApp/Baileys).

</p>

<p align="center">

Para mí, programar es el arte de transformar problemas complejos en soluciones eficientes, limpias y fáciles de mantener. Siempre enfocado en la mejora continua, el código bien estructurado y la entrega de valor en proyectos reales 🚀.

</p>
